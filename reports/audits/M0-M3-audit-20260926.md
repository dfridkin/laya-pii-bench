# Cross-milestone audit, M0-M3 (HEAD 37b7d51), 2026-09-26

Three independent read-only audits (subagents), consolidated and deduplicated here:
spec coverage (traceability of every M0-M3 build/gate item and spec clause), correctness and
test quality (edge cases, mutation testing on a repo copy), forward readiness (contracts,
feasibility and statistical power for M4-M8). Baseline at audit time: `make check` 160 passed,
7 skipped; model tests 7/7; `make fixture` 10/10; schema current; working tree clean.
Scratch evidence: session scratchpad `audit_spec/`, `audit_correct/`, `audit_forward/`.

Verdict: M0-M3 deliver what their gates test, but the audits found two blockers for M5/M6 as
specified, two high-severity validity holes in passed code (calib provenance, recall CI), and a
set of spec ambiguities the generator (M4) would otherwise have to guess.
